## 一、简历 bullet 版（2-3 行，放项目经历）

**GLP-1 药物 × AI 医药研发分析系统（辉瑞 AI Pilot 视角） | Python / NumPy / sklearn / SQL / Streamlit**
- 基于 ClinicalTrials.gov 真实数据（730 条 GLP-1 试验）构建**临床试验结果预测模型**：Logistic Regression / Random Forest / **numpy 手写 3 层 MLP 反向传播**（零框架依赖），5 折 CV AUC 达 0.82-0.83，识别申办方、适应症、分期等主导特征；
- **生物统计**：样本量/功效计算（二分类 + 连续终点，Chow 公式，呼应 I-IV 期试验设计）；**NLP**：730 条试验适应症文本挖掘研发热点关键词；
- 完整 **AI 落地 0→1 流水线**（数据接入 → 特征工程 → 建模评估 → SQL 数仓 → 自动报告），真实数据与仿真数据全程 `is_simulated` 标注。

## 二、STAR 完整版（面试讲述 / 作品集 README）

**背景（Situation）**：AI Pilot 要求"用 AI 解决医药研发真实问题、走通 0→1 落地"。选择研发场景中数据最开放、业务价值最直接的切面——**临床试验**：ClinicalTrials.gov 公开全部试验设计字段，AI 可回答"哪些试验更可能成功完成"，直接辅助管线决策。

**任务（Task）**：从 0 搭建一个可复现的 AI 研发分析系统：真实数据接入 → 特征工程 → 多模型对比（含手写神经网络）→ 统计设计支撑 → 自动化报告，全程数据可追溯。

**行动（Action）**：
1. **数据**：ClinicalTrials.gov API v2 抓取 730 条真实 GLP-1 试验（失败自动回退样例并提示）；FDA OpenFDA FAERS 真实不良事件；
2. **特征工程**：分期深度、适应症标志（obesity/diabetes/CV）、log(入组数)、申办方、启动年份；
3. **建模**：Logistic Regression（AUC 0.820）、Random Forest（AUC 0.830）、**numpy 手写 3 层 MLP 反向传播**（tanh 激活 + SGD，AUC 0.820，与 sklearn 持平证明实现正确）；5 折分层 CV + 含平局校正的 Mann-Whitney AUC；
4. **生物统计**：样本量/功效公式（二分类 392 例/组、连续终点 63 例/组的量级演示）；
5. **工程化**：SQLite 星型数仓 + 7 张分析 SQL + 一键流水线 + 自动高管简报（9 章）。

**结果（Result）**：交付可一键复现的 AI 研发分析闭环；模型识别出"申办方、适应症、分期"为成功率主导特征；简报同时覆盖安全信号（FAERS）与管线情报（NLP），可支撑研发/医学团队日常决策；全程数据诚实标注。

## 三、一句话版（自我介绍/投递备注）

"我用 ClinicalTrials.gov 的 730 条真实试验数据，从零搭了一条 AI 临床试验分析流水线：手写 MLP 反向传播预测试验完成概率（CV AUC 0.82-0.83），配样本量计算、NLP 管线挖掘和自动报告，完整演示了 AI 在医药研发场景 0→1 落地的全过程。"
